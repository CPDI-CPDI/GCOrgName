# Resources

This folder contains:
1) **Downloaded source datasets** (refreshed by automation), and
2) **Manual / curated inputs** required for correctness.

Most scripts in the daily pipeline read and write within `Resources/`.

---

## Key concepts

### Current truth vs history
- Current “truth” outputs are written to repo root:
  - `gc_concordance.csv`
  - `gc_org_info.csv`
- Historical lookup belongs in `Archives/` (generated by the archive workflow).

### Human-in-the-loop Receiver General (RG)
RG matching is intentionally human-reviewed.

#### RG files
- `rg_data.csv`  
  Raw RG dataset downloaded/standardized.
- `rg_matched.csv`  
  Machine candidate match per RG row (includes MatchScore).
- `rg_review_queue.csv`  
  Rows that require human review (low confidence, missing IDs, collisions, etc.).
- `rg_fixed.csv`  
  **Manual-authoritative** fixes for entries in the review queue.
- `rg_final.csv`  
  Resolved RG mapping used downstream. Built as:
  - all matched rows with **no issues**, plus
  - reviewed replacement rows from `rg_fixed.csv` for queued items.
- `rg_final_missing_fixes.csv` (optional)  
  Generated only when the review queue contains items with no corresponding fixes.

**Rule:** `rg_fixed.csv` is not a historical dumping ground; it is a response to the current review queue.

## Manual / curated files (high importance)

These should be edited intentionally and reviewed:
- `Manual org ID link.csv` — canonical mapping of organizations to `gc_orgID`
- `rg_fixed.csv` — RG review resolutions
- `lead_manual.csv` — lead department manual mappings (updated by `lead_fix.py`)
- `manual pop phoenix.csv` — HR/pay identifiers (manual)
- any other `manual*.csv` files

## If something looks “wrong”
- Check `rg_review_queue.csv` (RG issues)
- Check `unmatched_org_IDs.csv` (source records without `gc_orgID`)
- Check Actions logs for upstream schema changes
